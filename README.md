# Planagram — updates

The Sparkle update feed and notarised builds for Planagram, Common Era's Instagram feed planner.

This repo is public only because Sparkle sends no credentials and so can't read a private
feed. It holds the appcast and the built app; the source lives in a private repo.

To install: download the zip from the latest [release](https://github.com/common-era-uk/planagram-releases/releases),
unzip it, and drag Planagram into Applications. It updates itself from then on.
